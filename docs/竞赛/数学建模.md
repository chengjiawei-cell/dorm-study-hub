# 数学建模

## 📖 竞赛简介

数学建模竞赛是运用数学方法解决实际问题的团队竞赛，是大学生最广泛的学科竞赛之一。

| 项目 | 详情 |
|------|------|
| **主要赛事** | 全国大学生数学建模竞赛（CUMCM / 国赛）、美国大学生数学建模竞赛（MCM/ICM / 美赛） |
| **参赛形式** | 3 人组队，72-96 小时内完成建模、求解、论文 |
| **适合年级** | 大一即可参加 |
| **竞赛时间** | 国赛 9 月 / 美赛 1-2 月 |

---

## 🔧 常用工具

| 工具 | 用途 |
|------|------|
| **MATLAB** | 数值计算、优化建模 |
| **Python** (NumPy/SciPy/Matplotlib) | 数据处理、建模、可视化 |
| **LaTeX** | 论文排版（推荐） |
| **SPSS** | 统计分析 |
