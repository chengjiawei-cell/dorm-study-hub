# 🏆 竞赛指南

竞赛是大学期间提升能力、丰富简历的重要途径。这里整理了人工智能专业相关的各类竞赛信息。

---

## 📋 竞赛列表

<div class="grid cards" markdown>

-   :fontawesome-solid-chart-line:{ .lg .middle } **数学建模**

    ---

    全国大学生数学建模竞赛（CUMCM）、美国大学生数学建模竞赛（MCM/ICM）等。培养数学建模与论文写作能力。

    [:octicons-arrow-right-24: 查看详情](数学建模.md)

-   :fontawesome-solid-code:{ .lg .middle } **蓝桥杯**

    ---

    全国软件和信息技术专业人才大赛。涵盖 C/C++、Java、Python 等编程语言组别。

    [:octicons-arrow-right-24: 查看详情](蓝桥杯.md)

-   :fontawesome-solid-trophy:{ .lg .middle } **ICPC 程序设计竞赛**

    ---

    国际大学生程序设计竞赛。算法与数据结构的终极挑战，团队作战。

    [:octicons-arrow-right-24: 查看详情](ICPC程序设计竞赛.md)

-   :fontawesome-solid-robot:{ .lg .middle } **Kaggle 数据科学竞赛**

    ---

    全球最大的数据科学竞赛平台。真实数据集，实战机器学习与深度学习。

    [:octicons-arrow-right-24: 查看详情](Kaggle数据科学竞赛.md)

</div>

---

## 🗓️ 竞赛时间线

| 竞赛 | 大致时间 |
|------|---------|
| 数学建模（国赛） | 每年 9 月 |
| 数学建模（美赛） | 每年 1-2 月 |
| 蓝桥杯省赛 | 每年 4 月 |
| ICPC 区域赛 | 每年 10-11 月 |
| Kaggle | 全年滚动进行 |

---

!!! tip "经验之谈"
    建议大一可以先尝试数学建模和蓝桥杯练手，大二再挑战 ICPC 和 Kaggle 等更有难度的竞赛。
