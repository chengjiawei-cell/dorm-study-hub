# Kaggle 数据科学竞赛

## 📖 竞赛简介

Kaggle 是全球最大的数据科学竞赛平台，提供真实数据集和问题，涵盖机器学习、深度学习、NLP、CV 等领域。

| 项目 | 详情 |
|------|------|
| **平台** | [kaggle.com](https://www.kaggle.com/) |
| **参赛形式** | 个人或团队，在线提交 |
| **适合年级** | 大二及以上（需要 ML/DL 基础） |
| **竞赛类型** | Featured / Research / Getting Started / Playground |

---

## 📊 竞赛类型

| 类型 | 说明 | 难度 |
|------|------|:--:|
| **Getting Started** | 新手入门赛，有教程 | ⭐ |
| **Playground** | 练习赛，比较轻松 | ⭐⭐ |
| **Featured** | 商业赞助，奖金丰厚 | ⭐⭐⭐ |
| **Research** | 学术研究型 | ⭐⭐⭐⭐ |

---

## 🔧 常用技术栈

| 技术 | 用途 |
|------|------|
| **Python** | 主语言 |
| **PyTorch / TensorFlow** | 深度学习框架 |
| **Pandas / NumPy** | 数据处理 |
| **Scikit-learn** | 传统 ML |
| **Matplotlib / Seaborn** | 可视化 |
