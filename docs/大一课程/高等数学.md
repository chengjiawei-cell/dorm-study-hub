# 高等数学

## 📖 课程简介

高等数学是大学数学的基础课程，涵盖微积分、级数等内容，是后续所有理工课程的数学基础。

| 项目 | 详情 |
|------|------|
| **学分** | 上 5 学分 / 下 5 学分 |
| **学期** | 大一上 + 大一下 |
| **考核方式** | 平时作业 + 期中考试 + 期末考试 |
| **教材** | 《高等数学》（同济版） |
