# 体育

## 📖 课程简介

大学体育课程，包括基础体育和专项选修课。

| 项目 | 详情 |
|------|------|
| **学分** | 每学期 1 学分 |
| **学期** | 大一 + 大二 |
| **考核方式** | 平时出勤 + 技能考核 + 体能测试 |

---

## 🏃 课程安排

| 学期 | 内容 | 考核项目 |
|------|------|---------|
| 大一上 | 基础体育 | 跑步 / 引体向上 / 仰卧起坐 |
| 大一下 | 专项选修（自选） | 按项目考核 |
| 大二上 | 专项选修（自选） | 按项目考核 |
| 大二下 | 专项选修（自选） | 按项目考核 |

---

## 🏅 体测标准

| 项目 | 及格线（男） | 及格线（女） |
|------|:----------:|:----------:|
| 1000m / 800m | 4'30" | 4'30" |
| 50m | 9.0s | 10.2s |
| 引体向上 / 仰卧起坐 | 10个 | 27个/分 |

---

!!! tip "锻炼建议"
    体测成绩影响奖学金评定，建议平时保持规律锻炼，不要临时抱佛脚！
