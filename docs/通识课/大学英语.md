# 大学英语

## 📖 课程简介

大学英语综合课程，旨在提升英语听说读写能力，并为四六级考试做准备。

| 项目 | 详情 |
|------|------|
| **学分** | 每学期 2 学分 |
| **学期** | 大一 + 大二 |
| **考核方式** | 平时成绩 + 期末考试 |
| **相关考试** | CET-4 / CET-6 |
