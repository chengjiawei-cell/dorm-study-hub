# 📖 学习空间

---

## 📚 图书馆（钱学森图书馆）

| 项目 | 详情 |
|------|------|
| **位置** | 校园中心，南门进入直行即到 |
| **开放时间** | 待补充（通常 7:00-22:30） |
| **预约方式** | 图书馆微信公众号 / 网站预约 |
| **借书规则** | 凭校园卡借阅，本科生最多借 10 本 |
| **研讨室** | 可预约使用 |

---

## 🏫 自习室分布

| 位置 | 特点 |
|------|------|
| **图书馆** | 座位最多、环境最好 |
| **主楼教室** | 无课教室可自习 |
| **各书院自习室** | 距离宿舍近，方便 |
| **梧桐苑三楼 阅悦咖啡** | 咖啡+自习，氛围好 |

## ☕ 咖啡馆
