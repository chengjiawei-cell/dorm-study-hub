# 操作系统

## 📖 课程简介

操作系统是计算机系统的核心软件，学习进程管理、内存管理、文件系统、设备管理等核心概念。

| 项目 | 详情 |
|------|------|
| **学分** | 3 学分 |
| **学期** | 大二下 |
| **考核方式** | 平时作业 + 实验 + 期末考试 |
| **教材** | 《操作系统概念》/ 《现代操作系统》 |
