# 数据结构与算法

## 📖 课程简介

计算机科学核心课程，学习基本数据结构（数组、链表、栈、队列、树、图）和经典算法（排序、搜索、动态规划等）。

| 项目 | 详情 |
|------|------|
| **学分** | 4 学分 |
| **学期** | 大二上 |
| **考核方式** | 平时作业 + 实验 + 期末考试 |
| **教材** | 《数据结构》（严蔚敏）/ 《算法导论》 |
