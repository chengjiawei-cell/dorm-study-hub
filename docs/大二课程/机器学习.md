# 机器学习

## 📖 课程简介

人工智能核心课程，系统学习机器学习的基本理论和经典算法，包括监督学习、无监督学习、集成学习等。

| 项目 | 详情 |
|------|------|
| **学分** | 3 学分 |
| **学期** | 大二上 |
| **考核方式** | 平时作业 + 实验 + 期末考试/项目 |
| **教材** | 《机器学习》（周志华 西瓜书）/ 《统计学习方法》（李航） |
