# 计算机组成原理

## 📖 课程简介

学习计算机硬件系统的组成和工作原理，包括 CPU、存储器、总线、I/O 系统等。

| 项目 | 详情 |
|------|------|
| **学分** | 3 学分 |
| **学期** | 大二下 |
| **考核方式** | 平时作业 + 实验 + 期末考试 |
| **教材** | 《计算机组成原理》（唐朔飞）/ 《深入理解计算机系统》(CSAPP) |
