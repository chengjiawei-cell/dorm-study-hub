# 科学技术与工程伦理

## 📖 课程简介

探讨科学技术发展中的伦理问题，培养学生作为工程师和科研人员的伦理意识与社会责任感。

| 项目 | 详情 |
|------|------|
| **学分** | 待补充 |
| **学期** | 大一上 |
| **考核方式** | 平时成绩 + 期末考试/论文 |
| **教材** | 推荐购买课本（PPT不够全时课本最可靠） |

---

## 📚 课程大纲

| 章节 | 内容要点 |
|:--:|------|
| **第一章** | 工程基本概念（定义、由来、大工程观）、工程与社会（正面/负面作用）、工程伦理教育的历史与意义 |
| **第二章** | 道德与伦理的理解、伦理学定义与特征、主要理论（功利论、义务论、德性论）、伦理困境与决策 |
| **第三章** | 工程伦理问题概述（技术、利益、环境、责任）、环境伦理、医学伦理 |
| **第四章** | 工程风险（来源、可接受性、防范）、伦理评估原则与途径方法、伦理责任类型、工程价值多元化 |
| **第五章** | 可持续发展思想（形成、内涵）、资源与环境可持续发展 |
