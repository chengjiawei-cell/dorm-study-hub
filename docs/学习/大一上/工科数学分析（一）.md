# 工科数学分析（一）

## 📖 课程简介

工科数学分析是工科专业的核心数学基础课，涵盖一元函数微积分学的基本理论与应用。

| 项目 | 详情 |
|------|------|
| **学分** | 6 学分 |
| **学期** | 大一上 |
| **考核方式** | 平时作业 + 期中考试 + 期末考试 |
| **教材** | 《工科数学分析基础》 |
