# 学术英语素养

## 📖 课程简介

培养学生学术英语阅读、写作与口头表达能力，为后续英文文献阅读和学术交流打下基础。

| 项目 | 详情 |
|------|------|
| **学分** | 2 学分 |
| **学期** | 大一上 |
| **考核方式** | 平时成绩 + 期末考试 |
| **教材** | 待补充 |

---

## 🎯 课程目标

- 掌握学术英语的基本词汇和句式
- 能够阅读并理解英文论文摘要
- 具备基础的学术写作能力
- 能够进行简单的英文学术报告
