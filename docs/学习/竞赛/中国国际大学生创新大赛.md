# 中国国际大学生创新大赛

## 📖 竞赛简介

原「互联网+」大学生创新创业大赛，2023 年更名为中国国际大学生创新大赛，是国内规模最大、规格最高的大学生创新创业赛事。

| 项目 | 详情 |
|------|------|
| **全称** | 中国国际大学生创新大赛 |
| **前身** | 中国「互联网+」大学生创新创业大赛 |
| **参赛形式** | 团队参赛，提交商业计划书+路演答辩 |
| **适合年级** | 大一及以上 |
| **竞赛周期** | 校赛（4-5 月）→省赛（7-8 月）→国赛（10 月） |

---

## 📊 赛道设置

| 赛道 | 说明 |
|------|------|
| **高教主赛道** | 本科生/研究生创意组、初创组 |
| **青年红色筑梦之旅** | 乡村振兴、社区治理等 |
| **产业命题赛道** | 企业出题、学生揭榜 |
| **国际赛道** | 面向海外高校 |
