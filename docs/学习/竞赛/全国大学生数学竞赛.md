# 全国大学生数学竞赛

## 📖 竞赛简介

全国大学生数学竞赛（CMC）由中国数学会主办，是国内最具影响力的数学类学科竞赛之一，分为数学专业组和非数学专业组。

| 项目 | 详情 |
|------|------|
| **全称** | 全国大学生数学竞赛（CMC） |
| **参赛形式** | 个人参赛，笔试 |
| **组别** | 数学专业组 / 非数学专业组 |
| **适合年级** | 大一及以上 |
| **竞赛时间** | 初赛 10-11 月 / 决赛 次年 3-4 月 |

---

## 📊 考试内容

| 组别 | 考试内容 |
|------|------|
| **非数学专业组** | 高等数学（微积分、级数、微分方程） |
| **数学专业组** | 数学分析、高等代数、解析几何、概率论等 |
