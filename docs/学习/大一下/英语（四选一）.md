# 英语（四选一）

## 📖 课程简介

大一下学期英语四选一课程，从四个英语方向中选择一门修读，培养专项英语应用能力。

| 项目 | 详情 |
|------|------|
| **学分** | 2 学分 |
| **学期** | 大一下 |
| **考核方式** | 平时成绩 + 期末考试 |
| **教材** | 因方向而异 |

---

## 📚 可选方向（参考）

| 方向 | 侧重 |
|------|------|
| 英汉翻译 | 笔译技巧、翻译理论 |
| 英语写作 | 学术写作、应用文写作 |
| 英语演讲 | 口头表达、演讲技巧 |
| 跨文化交际 | 文化差异、交际策略 |

---

## 📝 学习建议

- 选课前向学长学姐了解各方向的难易和给分情况
- 四六级在大一尽快通过，为后续课程腾时间
