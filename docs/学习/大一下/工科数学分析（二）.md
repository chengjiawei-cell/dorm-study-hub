## 📚 常见考点

| 章节 | 重点 |
|------|------|
| **多元函数微分** | 偏导数、全微分、方向导数、梯度、极值 |
| **重积分** | 二重积分、三重积分、坐标变换 |
| **曲线曲面积分** | 格林公式、高斯公式、斯托克斯公式 |
| **无穷级数** | 数项级数判敛、幂级数展开、Fourier 级数 |
